# AI Analytics Dashboard - PRD

## 项目概述
AI驱动的数据分析与商业智能工具，通过自然语言交互生成SQL查询和可视化图表，支持多数据源接入。

## 目标用户
- 数据分析师（快速生成报表）
- 业务人员（无需SQL技能）
- 产品经理（数据驱动决策）

## 核心价值主张
- **自然语言查询**：用自然语言描述需求，自动生成SQL
- **智能可视化**：根据数据特征自动推荐最佳图表类型
- **多数据源支持**：SQLite/PostgreSQL/MySQL/ClickHouse
- **实时协作**：团队协作、权限管理

## 功能需求

### 核心功能
1. **自然语言查询**
   - 输入自然语言问题
   - AI生成SQL
   - 执行并返回结果
   - 结果可视化

2. **智能可视化**
   - 自动图表类型推荐
   - 多种图表：折线图、柱状图、饼图、表格
   - 自定义图表配置

3. **数据源管理**
   - 连接管理器
   - 多数据源支持
   - 连接测试

4. **报表系统**
   - 保存报表
   - 定时刷新
   - 导出（PDF/CSV/图片）

5. **协作功能**
   - 团队空间
   - 权限管理
   - 分享链接

### 技术需求
1. **后端**
   - Go + Gin框架
   - SQLite存储配置
   - PostgreSQL/MySQL适配器
   - DeepSeek LLM集成
   - REST API

2. **前端**
   - Next.js 14 App Router
   - ECharts/Recharts可视化
   - TypeScript类型安全
   - 响应式布局

3. **支付**
   - Stripe订阅
   - 免费额度限制
   - Pro功能解锁

## 商业模式
- **免费版**：10次查询/天，单数据源，基础图表
- **Pro版**：$19/月，无限查询，多数据源，高级图表
- **Team版**：$49/月/人，团队协作，权限管理

## 竞争优势
1. 自然语言交互降低使用门槛
2. AI自动生成优化SQL
3. 预置常用数据模型
4. 实时协作功能

## MVP范围
- 自然语言查询（DeepSeek生成SQL）
- SQLite数据源支持
- 基础图表（折线、柱状、饼图）
- 用户认证
- Stripe支付

## 技术栈
- 后端：Go 1.21+, Gin, SQLite, DeepSeek API
- 前端：Next.js 14, TypeScript, Recharts
- 部署：Docker, Render/ Railway
